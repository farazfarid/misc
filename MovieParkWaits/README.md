# Movie Park Waits

Live wait times for Movie Park Germany (Bottrop), on your phone or a big screen.

```bash
npm start          # http://localhost:3000, live data
npm run dev:mock   # offline sample data
npm test
```

Needs Node 18+. No `npm install` required. Data [Powered by Queue-Times.com](https://queue-times.com/parks/310).
